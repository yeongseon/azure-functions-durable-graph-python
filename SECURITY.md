# Security Policy

**Retired and unsupported as of 2026-10-02.** No maintenance, fixes or security
updates will be provided. `yeongseon` never published an official PyPI release of
`azure-functions-durable-graph`; a same-named PyPI project must not be treated as
official. Tags and GitHub releases are historical source snapshots only.

## Supported versions

**None.** No source snapshot or GitHub release receives security support. There is
no “latest supported release” and no planned security-fix publication.

## Voluntary private contact

To share a finding about the historical source privately, contact
yeongseon.choe@gmail.com or use the
[GitHub private reporting form](https://github.com/yeongseon/azure-functions-durable-graph-python/security/advisories/new)
if available. Include a description, reproduction steps, affected source commit,
impact and any suggested mitigation. Do not include secrets or personal data.

These channels carry **no commitment to respond, triage, remediate, publish an
advisory or coordinate a release**, and no response deadlines. Do not postpone
protecting your systems while waiting for a fix from this project.

## Historical checks

Local scans and retained CI configurations are not a security-support guarantee.
Dependency maintenance is not active. Revival requires an explicit maintainer
decision and updated, re-audited dependencies and Actions before workflows are
re-enabled, as recorded in
[PR #209](https://github.com/yeongseon/azure-functions-durable-graph-python/pull/209#issuecomment-5944447065).
